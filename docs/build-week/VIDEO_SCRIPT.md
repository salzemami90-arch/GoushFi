# Financial Calm Brief demo video

Target length: **2 minutes 35 seconds**. Maximum: **under 3 minutes**.

Record only the GoushFi product window. Start after signing in, keep Demo credentials off-screen, and do not show browser password managers, environment variables, dashboards, terminals, or production administration tools.

## Shot list and narration

### 0:00-0:12 - Title

**Shot**

- GoushFi logo or clean title card.
- Text: `Financial Calm Brief | OpenAI Build Week 2026`.

**Narration**

> Financial tools are good at showing numbers, but they often leave people wondering what to do next. Financial Calm Brief turns those numbers into three clear decisions.

### 0:12-0:32 - Existing product, new Build Week feature

**Shot**

- Briefly show the GoushFi Financial Analyzer in English.
- On-screen caption: `Existing product + new Build Week decision layer`.

**Narration**

> GoushFi is an existing bilingual financial-management product. During OpenAI Build Week, we used Codex to build and deploy Financial Calm Brief inside the real application.

### 0:32-1:14 - Three decisions

**Shot**

- Scroll slowly through the three English decision cards.
- Pause on each metric: `850.00 KWD`, `90.00 KWD`, and `1,130.00 KWD`.

**Narration**

> The first decision follows up eight hundred and fifty Kuwaiti dinars in open amounts. The second calms a ninety-dinar increase in Coffee and Outings. The third protects a positive one-thousand-one-hundred-and-thirty-dinar cash outlook for the next ninety days. The output is intentionally limited to exactly three priorities.

### 1:14-1:38 - Arabic parity

**Shot**

- Switch from English to Arabic.
- Return to Financial Analyzer if needed.
- Show the same three metrics in Arabic.

**Narration**

> GoushFi is bilingual. Switching to Arabic changes the presentation, not the facts. The same three financial amounts and priorities remain intact.

### 1:38-1:58 - Mobile view

**Shot**

- Show the 390 by 844 mobile viewport.
- Scroll through all three cards without horizontal overflow.

**Narration**

> The judging experience also works in a mobile-sized browser, while the existing iPhone WebView remains on the original report by design.

### 1:58-2:24 - Safety architecture

**Shot**

- Show a simple architecture card or the README diagram:
  `Financial data -> Python decisions -> optional GPT-5.6 explanation -> validator -> UI`.
- Highlight `Python owns every number` and `Deterministic fallback`.

**Narration**

> Python owns every calculation, title, action, priority, and financial number. GPT-5.6 is an optional explanation layer only. If an AI response changes the contract, introduces numeric claims, or the API is unavailable, GoushFi rejects it and uses a deterministic explanation instead. This judging build runs safely without an OpenAI API key.

### 2:24-2:35 - Close

**Shot**

- Return to the three cards or title card.
- Text: `Three trusted decisions. Less financial noise.`

**Narration**

> Financial Calm Brief: three trusted decisions, less financial noise, and a calmer next step.
